# GM6020双轴云台使用手册

## 指示灯描述

- 绿灯常亮：云台正常工作
- 绿灯闪烁：云台正在初始化或校准中
- 红灯常亮：电源接通但云台未启动
- 红灯闪烁：发生故障（如过流、通信异常等）

## 常见问题

**Q：云台通电后绿灯常亮代表什么？**  
A：表示云台已成功启动并处于正常工作状态。

**Q：为什么红灯在闪烁？**  
A：红灯闪烁表示云台检测到异常，如电机过流、CAN通信中断等，请检查接线及供电是否正常。

## 1. 系统综述

本云台系统是基于电控第三轮联调项目开发的双轴云台控制系统，采用Yaw-Pitch构型设计，具备两个自由度。

### 1.1 主要特性

- **双轴控制**：Yaw轴±60°，Pitch轴-15°~+45°运动范围
- **多模式运行**：支持自检、搜索、自瞄工作模式
- **安全保护**：多重失能保护机制，软件限位防护
- **姿态稳定**：基于BMI088陀螺仪的姿态解算和补偿

## 2. 硬件架构

### 2.1 核心组件

| 组件 | 型号规格 | 功能说明 |
|------|----------|----------|
| **主控芯片** | STM32F405RGT6 | 系统主控制器，HAL库开发 |
| **姿态传感器** | BMI088陀螺仪 | 六轴IMU，SPI通信接口 |
| **云台电机** | GM6020 × 2 | 无刷直流电机，CAN总线控制 |

## 3. 工作模式详解

### 3.1 开机自检模式

**启动流程：**
1. 系统上电，进行硬件自检
2. **指示灯状态**：黄色常亮
3. **电机自检**：
   - Yaw轴：缓慢转动±60°测试
   - Pitch轴：在-15°至+45°范围内转动测试
4. **IMU检测**：验证陀螺仪通信和数据有效性
5. 自检完成后进入等待连接状态

**等待连接状态：**
- **指示灯状态**：黄色慢闪
- **超时保护**：15秒内未连接将自动进入失能模式

### 3.2 工作模式

#### 3.2.1 搜索模式
- **触发条件**：成功建立通信连接后的默认状态，或接收到0x83指令
- **运动特性**：云台按预设轨迹自主运动，扫描搜索目标
- **通信要求**：上位机需以≥25Hz频率发送时间戳保持在线
- **指示灯**：绿灯常亮
- **失联保护**：500ms无通信将触发失能保护

#### 3.2.2 自瞄模式
- **触发条件**：接收到0x84指令（视觉识别到目标）
- **控制特性**：根据视觉反馈进行精确目标跟踪
- **通信要求**：上位机需以≥200Hz频率发送控制指令
- **指示灯**：绿灯快闪（约10Hz）
- **失联保护**：50ms无通信将触发失能保护

### 3.3 失能保护模式

**触发条件（任一满足即触发）：**
- 开机15秒内未成功连接上位机
- 搜索模式下通信中断超过500ms
- 自瞄模式下通信中断超过50ms
- IMU传感器数据异常或通信故障
- 电机反馈信号丢失超过20ms
- 电机角度解算值超出安全范围

**失能状态特征：**

- **电机状态**：立即断电失能，失去扭矩输出
- **恢复方式**：需发送0x88解锁指令重新使能

### 3.4 模式切换时序

```
开机自检 ──► 等待连接 ──► 搜索模式 ──► 自瞄模式
    │           │           │           │
    │           │           │           │
    ▼           ▼           ▼           ▼
  失能模式 ◄─── 失能模式 ◄─ 失能模式 ◄─ 失能模式
    │
    │ (0x88解锁)
    ▼
  搜索模式
```

## 4. 通信协议规范

### 4.1 数据帧格式

| 字段 | 字节数 | 数据类型 | 说明 |
|------|--------|----------|------|
| **帧起始** `SOF` | 2 | 0xAA 0x55 | 固定起始标志 |
| **数据长度** `LEN` | 1 | uint8_t | 数据区字节长度（不含识别码、CRC、包尾） |
| **识别码** `CMD` | 1 | uint8_t | 指令类型/来源标识 |
| **数据区** `DATA` | n | 自定义结构体 | 实际负载数据（yaw、pitch等） |
| **CRC校验** `CRC16` | 2 | uint16_t | 从SOF到DATA结束的CRC16校验（小端序） |
| **包尾** `EOF` | 2 | 0x5A 0xA5 | 固定结束标志 |

### 4.2 数据完整性

- **校验范围**：从帧起始0xAA开始到数据区结束
- **校验算法**：CRC16标准算法
- **字节序**：CRC16采用小端序存储
- **错误处理**：校验失败的数据包将被丢弃

## **控制码介绍**

1. 云台------>视觉    标识为0x01~0x09

   - 0x01 云台开机成功(默认归零模式，云台此时为自稳模式)

   - 0x02 云台方接收到0x81，云台方握手成功

   - 0x03 云台发送反馈数据

     `DATA`区如下

     ```C
     // cmd_id = 0x03 （数据反馈，数据区共 8 字节）
     typedef struct
     {
         int16_t yaw_target;		// 目前 yaw 角度 ×1000（度）
         int16_t pitch_target;	// 目前 pitch 角度 ×1000（度）
         int16_t roll_target;	// 目前 roll 角度 ×1000（度）
         uint8_t mode; 			// 目前云台工作模式
         uint8_t reserved;  		// (保留位)
     } AimControl_t;
     ```

   - 0x08 云台进入失能保护

2. 视觉----->云台     标识为0x81~0x89

   - 0x81 视觉方接收到云台开机成功指令0x01，视觉方请求连接

   - 0x82 视觉方接收到0x02，视觉方握手成功，可以开始流传输数据

   - 0x83 视觉丢失目标，云台进入搜索模式

   - 0x84 视觉成功识别目标，云台进入自瞄模式

     `DATA`区如下

     ```C
     // cmd_id = 0x84 （自瞄控制，数据区共 8 字节）
     typedef struct
     {
         int16_t yaw_target;   // 目标 yaw 角度 ×1000（度）
         int16_t pitch_target; // 目标 pitch 角度 ×1000（度）
         uint8_t fire_cmd;     // (保留位)0=不打，1=自动开火
         uint8_t anti_top;     // (保留位)0=关闭反陀螺，1=开启
         uint8_t reserved[2];  // (保留位)
     } AimControl_t;
     ```

   - 0x87 视觉方请求云台失能

   - 0x88 解锁失能云台

## 6. 故障诊断

### 6.1 指示灯描述

| 现象 | 描述 |
|----------|----------|
| 绿灯常亮 | 系统自检                 |
| 绿灯每隔1秒闪1次  | 等待连接中               |
| 绿灯每隔1秒闪10次 | 自瞄模式，成功识别装甲板 |

| 现象             | 可能原因      | 解决方案     |
| ---------------- | ------------- | ------------ |
| 黄灯每隔1秒闪1次 | 丢包警告      | 联系电控     |
| 黄灯每隔1秒闪2次 | 不明控制帧    | 检查串口代码 |
| 橙灯呼吸闪烁     | 进入DEBUG模式 | 重新上下电   |



| 现象             | 可能原因                 | 解决方案                   |
| ---------------- | ------------------------ | -------------------------- |
| 红灯常亮         | CAN通信异常              | 检查can总线连接            |
| 红灯每隔1秒闪1次 | 陀螺仪异常               | 检查陀螺仪排线连接         |
