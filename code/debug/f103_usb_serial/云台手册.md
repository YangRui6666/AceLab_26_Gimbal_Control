# GM6020双轴云台使用手册

## 1. 系统综述

本云台系统是基于电控第三轮联调项目开发的双轴云台控制系统，采用Yaw-Pitch构型设计，具备两个自由度。

### 1.1 主要特性

- **双轴控制**：Yaw轴`±60°`，Pitch轴`-15°`~+`45°`运动范围
- **多模式运行**：支持自检、搜索、自瞄工作模式
- **安全保护**：多重保护机制，软件限位防护
- **姿态稳定**：基于`BMI088`陀螺仪的姿态解算和补偿

## 2. 硬件架构

### 2.1 核心组件

| 组件 | 型号规格 | 功能说明 |
|------|----------|----------|
| **主控芯片** | `STM32F405RGT6` | 系统主控制器，`HAL库`开发 |
| **姿态传感器** | `BMI088`陀螺仪 | 六轴IMU，`SPI`通信接口 |
| **云台电机** | `GM6020` × 2 | 无刷直流电机，`CAN`总线控制 |
| **通信接口** | `Micro-USB` | 虚拟串口，与视觉系统通信 |

## 3. 工作流程

> 通讯包：用于通讯的指令
>
> 心跳包：用于连接保活的报文

### 3.1 开机自检

**开机流程：**

1. 系统上电，进行硬件自检
3. **电机自检**：
   - Yaw轴：在`±60°`范围内转动测试
   - Pitch轴：在`±42°`范围内转动测试
3. **IMU检测**：验证陀螺仪通信和数据有效性
5. 自检完成后进入**等待连接**状态

**等待连接状态：**

- **指示灯状态**：黄色慢闪
- **模式**：此时云台启动**对地**坐标轴的**自稳**
- **超时保护**：15秒内未连接将自动进入锁定模式

### 3.2 工作模式

以下内容按云台实际进入模式的先后顺序进行排版。若文档其他章节存在表述差异，以本节为准。

#### 3.2.1 稳定模式

- **切入条件**：开机自检完成后的**默认工作状态**，也是搜索模式超时后的**回退状态**，以及锁定保护模式解锁后的**返回状态**
- **工作特性**：Yaw、Pitch 电机回零后，保持**对地稳定**
- **切出条件**：
  - 自动切换
    - **心跳包**中断超过 **`1000ms`** 时，自动进入**`3.2.4 锁定保护模式`**

  - 手动切换
    - 接收到 **`0x83`** 指令，切换至**`3.2.2 搜索模式`**
    - 接收到 **`0x84`** 指令，切换至**`3.2.3 自瞄模式`**
    - 接收到 **`0x87`** 指令，切换至**`3.2.4 锁定保护模式`**


#### 3.2.2 搜索模式

- **切入条件**：接收到 **`0x83`** 指令，或自瞄模式超时后的自动降级
- **工作特性**：云台按预设轨迹**自主**运动（正弦函数）
- **切出条件**：
  - 自动切换
    - 超过**`500ms`**未接收到**通讯包**时，**自动降级**至**`3.2.1 稳定模式`**
    - **心跳包**中断超过 **`1000ms`** 时，自动进入**`3.2.4 锁定保护模式`**

  - 手动切换
    - 接收到 **`0x84`** 指令，切换至**`3.2.3 自瞄模式`**
    - 接收到 **`0x87`** 指令，切换至**`3.2.4 锁定保护模式`**


#### 3.2.3 自瞄模式

- **切入条件**：接收到 **`0x84`** 指令
- **工作特性**：根据视觉指令，控制云台运动到指定`Yaw-Pitch`
- **通信要求**：上位机需以不低于 200Hz 的频率发送控制指令，推荐 250Hz 以上（）
- **切出条件**：
  - 自动切换
    - 连续 **`200ms`** 未收到**通讯包**时，**自动降级**至**`3.2.2 搜索模式`**
    - **心跳包**中断超过 **`1000ms`** 时，自动进入**`3.2.4 锁定保护模式`**

  - 手动切换
    - 接收到 **`0x83`** 指令，切换至**`3.2.2 搜索模式`**
    - 接收到 **`0x87`** 指令，切换至**`3.2.4 锁定保护模式`**


#### 3.2.4 锁定保护模式

- **切入条件**：
  - 接收到 **`0x87`** 主动锁定指令
  - 开机后 15 秒内未成功连接上位机
  - **心跳包**中断超过 **`1000ms`**
- **状态特征**：云台立即**断电**，失去扭矩输出，停止一切正常控制动作
- **切出条件**：
  - 手动切换
    - 发送 **`0x88`** 解锁指令
    - 此时云台会退出锁定保护
    - 重新进入**`3.2.1稳定模式`**


#### 3.2.5 失能保护模式

***出现该情况时，请联系电控处理***

- **切入条件**：
  - IMU 传感器数据异常或通信故障
  - 电机反馈信号丢失超过 20ms
  - 电机角度解算值超出安全范围
- **状态特征**：电机立即**断电失能**，失去扭矩输出，程序终止
- **切出条件**：
  - 无法通过任何指令切出


**建议检查当前硬件机械连接，重启云台**

## 4. 通信协议规范

### 4.1 数据帧格式

| 字段 | 字节数 | 数据类型 | 说明 |
|------|--------|----------|------|
| **帧起始** `SOF` | 2 | `0xAA 0x55` | **固定**起始标志 |
| **数据长度** `LEN` | 1 | uint8_t | **数据区**字节长度（不含识别码、CRC、包尾） |
| **识别码** `CMD` | 1 | uint8_t | 指令类型/来源标识 |
| **数据区** `DATA` | n | 自定义结构体 | 实际负载数据（yaw、pitch等） |
| **CRC校验** `CRC16` | 2 | uint16_t | **从`SOF`到`DATA`结束**的CRC16校验（小端序） |
| **包尾** `EOF` | 2 | `0x5A 0xA5` | **固定**结束标志 |

### 4.2 数据完整性

- **校验范围**：从帧起始0xAA开始到数据区结束
- **校验算法**：CRC16标准算法
- **字节序**：CRC16采用小端序存储
- **错误处理**：校验失败的数据包将被丢弃

## **上位机编程指南**

枚举定义

```C
// 云台状态定义
typedef enum {
    GIMBAL_MODE_STABLE = 0,		//稳定模式
    GIMBAL_MODE_SEARCH = 1,		//搜索模式
    GIMBAL_MODE_AUTO_AIM = 2,	//自瞄模式
    GIMBAL_MODE_LOCK_PROTECT = 3,	//锁定模式
    GIMBAL_MODE_DISABLE = 4		//失能模式
} GimbalMode;
// 云台错误码定义
typedef enum {
    ERROR_NONE = 0,
    ERROR_MOTOR_OFFLINE = 1,
    ERROR_ENCODER_FAIL = 2,
    ERROR_LOCK = 9
} ErrorCode;
// 锁定原因定义（用于 0x08 报文的 msg 字段）
typedef enum {
    LOCK_REASON_MANUAL = 1,            // 主动锁定
    LOCK_REASON_BOOT_TIMEOUT = 2,      // 开机超时未连接
    LOCK_REASON_HEARTBEAT_TIMEOUT = 3  // 心跳超时
} LockReason;
```

1. **反馈** 

   **识别码**为`0x01`~`0x09`

   - `0x01` 云台开机报文
     `DATA`区如下

     ```C
      typedef struct
     {
         uint32_t time_stamp;	//	时间戳
     } ;
     ```
     
   - `0x02` 云台连接成功报文
     `DATA`区如下
   
     ```C
     typedef struct
     {
         uint32_t time_stamp;	//	时间戳
     } ;
     ```
     
   - `0x03` 云台发送反馈报文
   
     `DATA`区如下
   
     ```C
     // cmd_id = 0x03 （数据反馈，数据区共 12 字节）
     typedef struct
     {
         int16_t yaw_target;		// 目前 yaw 角度 ×1000（度）
         int16_t pitch_target;	// 目前 pitch 角度 ×1000（度）
         int16_t roll_target;	// 目前 roll 角度 ×1000（度）
         uint32_t time_stamp;    // 毫秒时间戳
         uint8_t mode; 			// 目前云台工作模式
         uint8_t reserved;  		// (保留位)
     } AimControl_t;
     ```
   
   - `0x08` 云台锁定报文
   
     `DATA`区如下
   
     ```C
     // cmd_id = 0x08 
     typedef struct
     {
         uint32_t time_stamp;	//	时间戳
         uint8_t msg;			//锁定原因，取值见 LockReason
     } ;
     ```
     
     
   
2. **控制**

   **识别码**为0x81~0x89

   - 0x81 连接云台

     `DATA`区为空

   - 0x82 开启数据传输

     `DATA`区为空

   - 0x83 进入搜索模式

   - 0x84 自瞄指令

     其中该命令的`DATA`区如下

     ```C
     // cmd_id = 0x84 
     typedef struct
     {
         int16_t yaw_target;   // 目标 yaw 角度 ×1000（度）
         int16_t pitch_target; // 目标 pitch 角度 ×1000（度）
         uint32_t time_stamp;	//	时间戳
         uint8_t reserved[2];  // (保留位)
     } AimControl_t;
     ```
     
   - 0x85 在线心跳包

     `DATA`区定义如下

     ```c
     // cmd_id = 0x85
     typedef struct
     {
         uint8_t mode;
         uint32_t time_stamp;	//	时间戳
     } AimControl_t;
     ```

     `mode` 字段用于携带上位机当前模式信息，当前协议中仅用于连接保活，不直接触发云台模式切换

   - 0x87 请求云台锁定

     `DATA`区为空

   - 0x88 请求退出锁定模式，进入稳定模式

     `DATA`区为空

   > ~~3. DEBUG指令~~
   >    - ~~0xD0 进入debug模式~~
   >    - ~~0xD1 开启统计信息（每1s上报一次数据）~~

## 5. 系统集成指南

### 5.1 开发环境配置

- **开发工具链**：Cmake
- **编程语言**：C语言（HAL库）
- **实时操作系统**：FreeRTOS
- **主控制频率**：1kHz
- **通信接口**：USB虚拟串口

### 5.2 关键技术实现

#### 5.2.1 姿态解算
- 基于BMI088六轴IMU数据融合
- 采用互补滤波
- 实现世界坐标系下的姿态稳定

#### 5.2.2 电机控制
- GM6020无刷电机CAN总线控制
- PID闭环位置控制
- 软件限位保护机制

#### 5.2.3 多任务调度
- FreeRTOS实时任务管理
- 高优先级控制任务（1kHz）
- 通信任务与状态管理任务

## 6. 故障诊断

### 6.1 指示灯描述

| 现象 | 描述 |
|----------|----------|
| 绿灯常亮 | 系统自检                 |
| 绿灯每隔1秒闪1次  | 等待连接中               |
| 绿灯每隔1秒闪10次 | 自瞄模式，成功识别装甲板 |

| 现象             | 可能原因      | 解决方案     |
| ---------------- | ------------- | ------------ |
| 黄灯每隔1秒闪1次 | 丢包警告      | 联系电控     |
| 黄灯每隔1秒闪2次 | 不明控制帧    | 检查串口代码 |
| 橙灯呼吸闪烁     | 进入DEBUG模式 | 重新上下电   |



| 现象             | 可能原因                 | 解决方案                   |
| ---------------- | ------------------------ | -------------------------- |
| 红灯常亮         | CAN通信异常              | 检查can总线连接            |
| 红灯每隔1秒闪1次 | 陀螺仪异常               | 检查陀螺仪排线连接         |
| 红灯每隔1秒闪2次 | 云台机械限位冲突         | 检查云台放置位置           |
| 红灯每隔1秒闪3次 | 开机后无法连接上位机     | 检查通信连接，发送0x88解锁 |
| 红灯每隔1秒闪4次 | 运行过程中上位机断开连接 | 检查USB连接和上位机程序    |
