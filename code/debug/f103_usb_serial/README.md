# 测试板程序
通过usb虚拟串口通讯，通过串口协议进行数据交互。该程序为模拟板，旨在测试串口通讯。
在此程序中，成功建立连接后，yaw的值为sin函数，pitch的为cos函数，roll的为0。

### 1.关于时间戳的规定

在此测试板程序中，时间戳的交互模式如下：
1. 当云台接收到 0x81 后，云台方返回 0x02，包含系统时间戳
2. 视觉方接收到 0x02 后，握手成功，开始流传输数据
3. 云台在发送反馈数据（0x03）时，数据区包含当前系统时间戳
4. 视觉方发送自瞄控制指令（0x84）时，数据区包含目标时间戳
5. 双方通过时间戳进行数据同步和延迟计算

说明：项目内所有时间戳统一使用 `uint32_t` 毫秒计数。

### 2.失能保护

**触发条件：**

- 开机15秒内未成功连接上位机
- 搜索模式下通信中断超过500ms
- 自瞄模式下通信中断超过50ms

**失能状态特征：**

- **LED状态**：板载绿色LED闪烁
- **恢复方式**：需发送0x88解锁指令重新使能

### 模式切换时序表

```
开机自检 ──► 等待连接 ──► 搜索模式 ──► 自瞄模式
    │           │           │           │
    │           │           │           │
    ▼           ▼           ▼           ▼
  失能模式 ◄─── 失能模式 ◄─ 失能模式 ◄─ 失能模式
    │
    │ (0x88解锁)
    ▼
  搜索模式
```

## 通信协议

### 3.1 数据帧格式

| 字段                | 字节数 | 数据类型     | 说明                                    |
| ------------------- | ------ | ------------ | --------------------------------------- |
| **帧起始** `SOF`    | 2      | 0xAA 0x55    | 固定起始标志                            |
| **数据长度** `LEN`  | 1      | uint8_t      | 数据区字节长度（不含识别码、CRC、包尾） |
| **识别码** `CMD`    | 1      | uint8_t      | 指令类型/来源标识                       |
| **数据区** `DATA`   | n      | 自定义结构体 | 实际负载数据（yaw、pitch等）            |
| **CRC校验** `CRC16` | 2      | uint16_t     | 从SOF到DATA结束的CRC16校验（小端序）    |
| **包尾** `EOF`      | 2      | 0x5A 0xA5    | 固定结束标志                            |

### 3.2 数据完整性

- **校验范围**：从帧起始0xAA开始到数据区结束
- **校验算法**：CRC16/MODBUS（初值 `0xFFFF`，多项式 `0xA001`）
- **字节序**：CRC16采用小端序存储
- **错误处理**：校验失败的数据包将被丢弃

## **控制码介绍**

1. 云台------>视觉    标识为0x01~0x09

    - 0x01 云台开机成功(默认归零模式，云台此时为自稳模式)

    - 0x02 云台方接收到0x81，云台方握手成功
        此时`DATA`区如下
        ```C
         uint32_t time_stamp;    // 毫秒时间戳
        ```
    - 0x03 云台发送反馈数据

      `DATA`区如下

      ```C
      // cmd_id = 0x03 （数据反馈，数据区共 12 字节）
      typedef struct
      {
          int16_t yaw_target;		// 目前 yaw 角度 ×1000（度）
          int16_t pitch_target;	// 目前 pitch 角度 ×1000（度）
          int16_t roll_target;	// 目前 roll 角度 ×1000（度）
          uint32_t time_stamp;    // 毫秒时间戳
          uint8_t mode; 			// 目前云台工作模式
          uint8_t reserved;  		// (保留位)
      } AimControl_t;
      ```

    - 0x08 云台进入失能保护

### 云台工作模式枚举

```C
// 云台工作模式定义
typedef enum
{
    MODE_DISABLED     = 0,  // 失能保护模式
    MODE_STANDBY      = 1,  // 待机/归零模式 (默认上电模式)
    MODE_SEARCH       = 2,  // 搜索模式 (丢失目标时)
    MODE_AUTO_AIM     = 3,  // 自瞄模式 (识别到目标时)
    MODE_MANUAL       = 4,  // 手动控制模式 (保留)
} CloudMode_t;
```

**模式说明：**
- **失能保护模式 (0)**：电机断电，需发送 0x88 解锁
- **待机/归零模式 (1)**：云台初始化归零，等待指令
- **搜索模式 (2)**：云台按预定轨迹搜索目标
- **自瞄模式 (3)**：云台跟踪视觉提供的目标坐标
- **手动控制模式 (4)**：预留，用于手动遥控控制

2. 视觉----->云台     标识为 0x81~0x89

    - 0x81 视觉方接收到云台开机成功指令0x01，视觉方请求连接

    - 0x82 视觉方接收到0x02，视觉方握手成功，可以开始流传输数据

    - 0x83 视觉丢失目标，云台进入搜索模式

      - 0x84 视觉成功识别目标，云台进入自瞄模式

        `DATA`区如下

        ```C
        // cmd_id = 0x84 （自瞄控制，数据区共 10 字节）
        typedef struct
        {
            int16_t yaw_target;   // 目标 yaw 角度 ×1000（度）
            int16_t pitch_target; // 目标 pitch 角度 ×1000（度）
            uint32_t time_stamp;  // 毫秒时间戳
            uint8_t fire_cmd;     // (保留位)
            uint8_t anti_top;     // (保留位)
          
        } AimControl_t;
        ```

    - 0x87 视觉方请求云台失能

    - 0x88 解锁失能云台

### 4. LED 灯状态指示

LED 硬件连接：绿色 LED 连接至 PC13 引脚（低电平点亮）。LED的用户标签为`LED_GREEN`

**灯语状态说明：**

| LED 状态          | 含义             | 说明                           |
|-----------------| ---------------- | ------------------------------ |
| **快闪** (100ms)  | USB 通信正常     | 系统正常运行，USB 串口发送数据 |
| **慢闪** (500ms)  | 等待连接         | 已开机但未建立 USB 连接        |
| **led1s亮100ms** | 失能保护模式     | 云台进入保护状态，需解锁       |
| **常灭**          | 系统故障/未供电 | 程序异常或硬件故障             |

**注意事项：**
- LED 采用低电平驱动方式（GPIO 输出低电平时点亮）
- 在失能保护模式下，LED 会以特定频率闪烁提示错误类型
- 调试模式下可通过 LED 状态快速判断系统工作状态


文件架构：
测试板固件核心逻辑位于 `Core/Src/usb.c` 和 `Core/Src/LED.c`。
`main.c` 负责初始化并轮询调用业务任务。
USB CDC 底层接收桥接位于 `USB_DEVICE/App/usbd_cdc_if.c`。
主机侧联调脚本位于 `tools/usb_host.py`。

## 构建

### 固件

```powershell
cmake --preset Debug
cmake --build --preset Debug
```

### 主机侧联调脚本

依赖：

```powershell
python -m pip install pyserial
```

运行示例：

```powershell
python tools\usb_host.py --port COM5
```

脚本启动后会自动发送 `0x81` 握手请求，并提供以下交互命令：

- `handshake`：重新发送 `0x81`
- `search`：持续发送 `0x83` 保持搜索模式
- `auto <yaw_deg> <pitch_deg>`：持续发送 `0x84` 保持自瞄模式
- `disable`：发送 `0x87`
- `unlock`：发送 `0x88`
- `stop`：停止周期控制命令发送
- `quit`：退出脚本

## 当前实现行为

- 上电后尝试发送一次 `0x01`
- 握手成功后进入搜索模式并以 100Hz 周期发送 `0x03`
- `yaw = 30deg * sin(t)`，`pitch = 15deg * cos(t)`，`roll = 0`
- 搜索模式 500ms 超时、自瞄模式 50ms 超时、上电 15s 未建立会话均进入失能
- 失能状态下仅接受 `0x88` 解锁
